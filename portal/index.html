HOW TO COMPARE

One active scene.
One clear frame budget.

  1. Start with the default view. Let shaders compile and the frame rate settle.
  2. Increase complexity gradually. Watch object counts, frame time, and adaptive quality—not just FPS.
  3. Keep the conditions consistent. Use the same window size and run one demo at a time. The exhibition shares its layout, crowd counts and camera across engines. Materials and effects still differ, so treat results as practical scene comparisons rather than identical GPU workloads.
